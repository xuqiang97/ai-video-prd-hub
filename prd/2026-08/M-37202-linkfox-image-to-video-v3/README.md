## 业务背景和价值

AI 商品视频现运行于 ERP“产品开发系统”内的 Java 独立菜单模块，入口为“AI视频 > 任务管理”。当前系统使用 LinkFox 图转视频 V2 建任务接口，已接入 Seedance 2.0、Seedance 2.0 Fast、Seedance 2.0 Mini 和 HappyHorse 4 款模型。

LinkFox V3 已将图转视频模型调整为具体版本化 `videoType`，而 V2 分享文档未完整覆盖当前 Java 已接入的模型。本需求以 ERP 现网、当前 Java 真实 V2 请求与响应及 LinkFox V3 文档为基线，升级建任务接口及模型映射；不将旧文档或未经确认的 V2 停服时间作为实施依据。

本期不改变现有页面、配置项和视频生成业务规则，保证现有 4 款模型继续正常创建任务并复用当前结果查询链路。

## 需求概述

1. 图转视频建任务由 V2 统一切换至 V3，现有 4 款模型改用 V3 版本化 `videoType`。
2. 除完整建任务接口地址和 `videoType` 请求值外，当前实际使用字段的名称、类型和业务取值规则保持不变。
3. “获取作图结果”继续使用现有 V2 查询接口，现有轮询、结果处理和任务流转保持不变。
4. 现有 4 款模型的 LinkFox 图转视频算力计费口径保持不变。
5. 本需求不新增模型、页面或明显交互，不需要 HTML 原型。

## 功能需求

### 1. 建任务接口升级

| 接口用途 | 当前接口 | 本期处理 |
|---|---|---|
| 图转视频建任务 | `/linkfox-ai/image/v2/make/imageToVideo` | 升级为 `/linkfox-ai/image/v3/make/imageToVideo` |
| 获取作图结果 | `/linkfox-ai/image/v2/make/info` | 保持不变 |

当前实际使用的建任务字段在 V2、V3 中名称和类型保持不变，本期主要改造点为替换完整建任务接口地址，并将 `videoType` 的请求值更新为 V3 版本化模型标识：

| 当前实际使用字段 | V2、V3 对照结论 | 本期处理 |
|---|---|---|
| `imageList` | 字段名及 `array[string]` 类型不变 | 继续传现有多图参考图列表 |
| `videoTime` | 字段名及 `number` 类型不变 | 继续按现有规则传 `5` 秒 |
| `prompt` | 字段名及 `string` 类型不变；V3 明确未传 `templateKey` 时必须传入 | 继续传当前视频提示词，不使用模板模式 |
| `promptOptimizer` | 字段名及 `boolean` 类型不变 | 继续按现有页面选择传递 |
| `resolution` | 字段名及 `string` 类型不变 | 继续按现有页面选择及模型限制传递 |
| `voice` | 字段名及 `boolean` 类型不变 | 继续按现有页面选择及模型限制传递 |
| `aspectRatio` | 字段名及 `string` 类型不变 | 继续按现有页面选择传递 |
| `videoType` | 字段名及 `string` 类型不变，请求值由 V2 模型标识调整为 V3 版本化模型标识 | 按“现有模型映射”更新 4 款模型的请求值 |

处理规则：

1. 所有当前实际会创建 LinkFox 视频任务的现有入口统一复用 V3 建任务链路，不得出现部分入口继续调用 V2 的情况。
2. 必须替换完整建任务接口地址，不得把结果查询接口同步改为 V3。
3. V3 建任务失败时沿用现有失败处理，不自动回退 V2 或切换其他模型。
4. 上线前确认生产账号已开通 V3 及本期 4 款模型的调用权限；上线后通过实际出站请求确认新任务不再调用 V2 建任务接口。

### 2. 现有模型映射

| 页面现有模型 | V3 `videoType` |
|---|---|
| Seedance 2.0 | `doubao-seedance-2-0` |
| Seedance 2.0 Fast | `doubao-seedance-2-0-fast` |
| Seedance 2.0 Mini | `doubao-seedance-2-0-mini` |
| HappyHorse | `happyhorse-v2` |

- 页面继续保留现有 4 款模型的名称、顺序、默认值和选择逻辑，不因 V3 文档包含其他模型而新增选项。
- V3 `videoType` 仅用于 LinkFox 建任务请求。当前 V2 请求值由研发根据现行 Java 代码和真实请求定位，不根据旧文档或页面名称反推；本期不改变已保存的业务模型标识、历史任务或结果展示。

### 3. 现有请求与页面配置保持不变

- 当前 4 款模型继续只使用 `imageList` 多图参考图列表生成，不使用 `imageUrl` 单图或首帧模式，也不使用 `lastFrameImageUrl` 首尾帧模式。
- 视频分辨率、宽高比、`voice` 和 `promptOptimizer` 继续按现有页面选择及模型动态限制传递；现有默认值、自动重置、启用和置灰逻辑不调整。
- 当前仍只开放 5 秒视频、16:9 标准横屏和 9:16 标准竖屏，不开放 V3 新增的时长、分辨率、比例或多图能力。
- ERP 继续传递当前视频提示词，不使用 V3 模板模式，不传 `templateKey`、`productInfo`、`language` 或 `saleCountry`。

研发需以当前 Java 真实 V2 请求与响应为基线，对照 V3 文档完成实际使用字段、任务 ID、响应及错误返回的兼容核对；资料不一致时先反馈产品或 LinkFox 确认，不自行改变现有业务规则。

### 4. 算力计费保持不变

- 本期 4 款模型继续采用 LinkFox 算力说明中“图转视频”章节 `/imageToVideo` 的对应计费口径，不引用其他视频功能的计费表，也不新增或调整页面算力展示、本地扣费计算和价格快照。
- 提测和上线前再次核对 LinkFox 最新“图转视频”价格表；若上游计费已变化，先反馈产品确认，不在接口升级中静默调整。

### 5. 结果查询与任务兼容

1. V3 建任务成功后，继续使用返回的任务 ID 调用 `/linkfox-ai/image/v2/make/info` 查询结果。
2. 现有轮询、状态判断、结果解析、视频保存和 ERP 任务流转保持不变，不新增回调或状态规则。
3. V2 创建的进行中任务继续使用现有查询链路直至最终状态；已完成任务、视频结果和审核结论不回刷、不改写。
4. 上线后重新创建 LinkFox 视频任务时调用 V3，原任务和原结果记录保持不变。

## 不在本期范围

- 新增 Seedance 2.5、MiniMax H3 或 V3 文档中的其他模型；
- 新增单图、首尾帧、模板模式或新的时长、分辨率、宽高比、多图范围；
- 调整页面交互、算力展示、本地计费或“获取作图结果”链路；
- 历史任务或历史视频回刷。

## 风险描述

| 风险 | 处理方式 |
|---|---|
| V2 分享文档未完整反映当前 Java 已接入模型 | 以当前 Java 真实 V2 请求与响应为基线，核对 V3 模型映射和实际使用字段，不根据旧文档推测现网常量。 |
| 生产账号未开通 V3 或某个目标模型 | 提测和上线前使用生产同等权限账号完成 4 款模型的正常建任务验证。 |
| 接口升级误改稳定链路或沿用错误计费口径 | 改造限定为建任务地址及 `videoType` 映射；回归现有页面和查询链路，并在提测、上线前核对“图转视频”价格表。 |
