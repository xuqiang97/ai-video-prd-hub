## 业务背景和价值

AI 商品视频现已迁移为 ERP“产品开发系统”内的 Java 独立菜单模块，入口为“AI视频 > 任务管理”。本期把 5 项代码提示词迁移到专用配置表，使授权人员可通过维护接口调整默认提示词，必要时由数据库维护人员通过 SQL 调整，无需改代码、发版或重启服务。

本需求以 ERP 现网、当前 Java 代码和真实接口为准；历史 Python MVP 和 https://github.com/xuqiang97/ai_video 只作为背景。

## 需求概述

1. 新建 AI 视频专用提示词配置表，初始化当前 Java 现网使用的 5 项提示词。
2. 生成链路改为读取配置表，不再使用代码常量或以旧常量兜底。
3. 提供配置查询接口和单项正文修改接口。
4. 生成总分镜脚本时，固定硬规则放在 system，软风格移至 user.content[0]。
5. 页面维持现有布局和三种软风格，仅新增软风格正文非空校验。

本需求不新增页面、不需要 HTML 原型，也不拆分独立需求。

## 功能需求

### 1. 配置范围与设计原则

全系统共用一套配置，不按用户、店铺、商品、类目、脚本模型或视频模型拆分。

| 配置键 | 配置名称 | 使用位置 |
|---|---|---|
| FIXED_PROMPT | 固定硬规则 | 第二步左侧、生成总分镜脚本 |
| RADICAL_PROMPT | 激进版 | 第二步右侧 |
| BALANCED_PROMPT | 平衡版 | 第二步右侧 |
| CONSERVATIVE_PROMPT | 保守版 | 第二步右侧 |
| VIDEO_GENERATION_PROMPT_SUFFIX | 视频生成提示词默认后缀 | 第三步固定统一后缀、视频片段生成 |

新建 AI 视频专用配置表，每项 Prompt 或每种软风格保存为一条独立记录。表结构应保留稳定配置标识、名称、类型、正文、排序、默认、推荐、启用状态和修改审计等必要能力，具体表名、字段、类型和索引由研发按现行 Java 项目规范设计。

配置表须预留软风格扩展能力：未来增加第 4、第 5 种风格时，可通过新增记录实现，不需要增加表字段或迁移现有记录。本期页面仍只使用现有三种风格，其名称、顺序、默认选中项和推荐标识保持现网一致。

5 项初始正文必须从当前 Java 现网代码原样迁移。当前 ERP 第三步“最终提示词模板”中的固定统一后缀迁移为 VIDEO_GENERATION_PROMPT_SUFFIX，不得按某个具体视频模型命名。初始化不得顺带修改、格式化或优化正文。

迁移后，5 项提示词均以数据库配置为准，不再使用代码常量或在配置异常时回退到旧常量。

### 2. 查询与修改接口

- 提供当前 5 项配置的查询接口，以及按配置键修改单项提示词正文的接口；不提供批量修改、新增或删除能力。
- 具有现有 AI 视频任务页面访问权限的已登录用户可以读取配置；只有被授权的研发、产品或运维账号可以修改。
- 修改正文不能为空，并须完整保留长文本、换行和特殊字符；修改失败时不得影响原配置及其他配置。
- 接口或 SQL 修改成功后，再次查询或刷新任务步骤即使用最新值，无需发版或重启，并记录最后修改人和时间。
- 日常优先通过维护接口修改，SQL 仅作为保留维护方式，并且只允许具备现有数据库维护权限的人员操作。
- 建议查询使用 GET、单项修改使用 PUT；具体接口路径、请求响应结构、鉴权和缓存方案由研发按现行 ERP Java 规范设计，并补充正式接口文档。

### 3. 任务页面与总分镜脚本调用

用户进入或刷新第二步“生成总分镜脚本配置”时加载配置：

- 左侧固定硬规则只读；
- 右侧仍为激进版、平衡版、保守版三选一，并允许当前任务临时编辑；
- 临时内容仅用于本次生成，不更新配置表；
- 临时内容为空或纯空白时阻止生成，并提示“风格模板内容不能为空”；
- 页面加载后配置被正常修改为另一有效内容，本次仍使用页面已展示内容；重新进入或刷新后才使用新值。

亚马逊 Listing 店铺 + ASIN、产品库系统 SKU 两种资料来源均使用相同规则。当前 5 个脚本生成模型共用同一套配置：

- GPT-5.6-sol
- GPT-5.5
- Gemini 3.1 Pro Preview
- Gemini 3.5 Flash
- Seed 2.0

生成总分镜脚本时：

1. system.content 只放当前任务加载的 FIXED_PROMPT。
2. user.content 为多模态数组，第一个元素固定为当前选中或临时编辑后的软风格 text。
3. 后续按现有顺序放商品图片、商品标题、类目、尺寸、有效卖点，最后放“总视频时长：XX秒”。
4. VIDEO_GENERATION_PROMPT_SUFFIX 不参与总分镜脚本生成。

除上述消息角色调整外，不改变模型映射、商品资料来源、总视频时长格式及其他底层调用规则。认证信息继续使用现有安全配置，不进入配置表、页面、接口示例或日志明文。

### 4. 视频生成提示词默认后缀

第三步“最终提示词模板”中的固定统一后缀对应 VIDEO_GENERATION_PROMPT_SUFFIX，不包含动态分镜正文或下方视频生成参数。

最终视频提示词 = 当前分镜正文 + VIDEO_GENERATION_PROMPT_SUFFIX。

新任务首次生成使用当前任务已经加载并展示的后缀；历史任务单段重做和失败重试读取调用时最新后缀。现有模型提供商、视频模型、分辨率、宽高比、音频和智能提示词优化等参数不变。

### 5. 异常与历史任务

- 任一配置缺失、重复、停用、正文为空或读取异常时，配置加载整体失败，提示“Prompt 配置异常，请联系研发”，不得以部分配置、历史缓存或代码常量兜底。
- 生成总分镜脚本前，后端再次校验固定硬规则和三种软风格；视频生成、单段重做和失败重试前，再次校验视频生成提示词默认后缀。
- 有效配置修改只影响修改后重新加载配置的新调用；已经加载页面的当前操作仍使用页面已展示内容。配置变为无效状态时按本节异常规则阻止生成，不回改已经生成的分镜、视频和审核结论。
- 历史任务重新生成总分镜脚本时加载最新固定硬规则和三种风格默认值，用户本次选择或编辑的软风格内容优先，并采用本期新的消息结构；不执行历史数据回刷。
- 本期不新增 Prompt 快照或配置版本历史。当前 Java 已经保存的风格、分镜或最终提示词记录保持不变。

## 不在本期范围

- Prompt 配置管理页面、个人模板；
- 新增、删除、停用配置，批量修改，动态增加软风格；
- 配置版本、审批、灰度、回滚、A/B Test、Prompt 快照和历史回刷；
- 按用户、店铺、商品、类目或模型维护不同配置；
- 初始化过程中优化或改写现有 5 项 Prompt 正文及内容规则；
- Few-shot、显式分镜数量、输出校验、自动修复或重试；
- 调整现有脚本模型、视频模型、视频参数和页面布局。

## 风险描述

- 修改接口会直接影响后续任务，必须限制修改权限。
- 本期没有 Prompt 快照和配置版本，更新后可能无法完整还原历史任务当时使用的系统默认内容。
- 初始化必须以当前 Java 现网正文为准，不得使用历史仓库或旧原型。
- 软风格从 system 移到 user 后，须由视频提示词算法工程师完成 5 个脚本模型的效果回归。

## 验收标准

1. 配置表中存在本期 5 项配置，正文与当前 Java 现网逐字符一致；每种软风格独立保存，未来新增风格不需要增加表字段。
2. 查询接口可完整返回当前 5 项配置；配置不完整或异常时返回明确失败。
3. 被授权账号可按配置键修改单项正文；非法键、空正文、未授权或写入失败时原配置及其他配置不变。
4. 接口或 SQL 将配置修改为另一有效内容后，再次查询或刷新任务步骤即可读取最新内容和修改信息，无需发版或重启；已经加载页面的当前操作继续使用页面已展示内容。SQL 仅由具备现有数据库维护权限的人员操作。
5. 左侧固定硬规则保持只读；右侧三种风格的名称、顺序、默认选中项和推荐标识与现网一致，可单次编辑且不影响系统默认值，空内容被阻止。
6. 亚马逊 Listing 店铺 + ASIN 和产品库系统 SKU 两种入口均使用相同配置和调用规则。
7. 5 个脚本模型的 system.content 均只包含固定硬规则，user.content[0] 均为当前软风格，后续商品图文信息和总视频时长顺序正确。
8. 第三步固定统一后缀完整展示并参与视频提示词组合，不混入动态分镜正文或视频参数。
9. 配置缺失、重复、停用、正文为空或读取异常时，相关生成被阻止且不以部分配置、历史缓存或代码常量兜底。
10. 历史结果不被改写；历史任务重新生成总分镜脚本时加载最新固定硬规则和三种风格默认值，用户本次选择或编辑的软风格内容优先，并采用新消息结构；单段重做或失败重试采用最新后缀。
11. 本期未新增配置页面、动态软风格、Prompt 版本、快照、回刷、Few-shot 或其他明确排除能力。
12. 提测前，算法工程师完成 5 个脚本模型效果回归，确认固定硬规则、输出格式和三种风格表现可接受。
